# Pharmacy Staff Guide - Install on Phone and Daily Use

This guide is for pharmacy staff using the Bawaza Pharmacy Assistant app.

---

## 1) Connect to pharmacy Wi-Fi

1. Connect your phone to the pharmacy Wi-Fi network.
2. Open browser and visit: `https://pharmacy-app.local/` (or the URL your manager gives).

---

## 2) Install app on Android (Chrome)

1. Open app URL in Chrome.
2. Tap the **3 dots** menu.
3. Tap **Install app** or **Add to Home screen**.
4. Confirm install.
5. App icon appears on home screen.

---

## 3) Install app on iPhone (Safari)

1. Open app URL in Safari.
2. Tap **Share** icon.
3. Select **Add to Home Screen**.
4. Tap **Add**.
5. App icon appears on home screen.

---

## 4) First login

1. Open app from home screen icon.
2. Enter your assigned email/password.
3. Tap **Sign in**.

If no account exists:
- Tap **Create account** and follow manager policy.

---

## 5) Daily workflow

## A. Search medicine quickly
1. In search bar, type brand or generic name.
2. Check shelf/zone shown in result.
3. If medicine says **⚠ Prescription required**, confirm proper prescription process.

## B. Update location
1. Tap **Edit** on medicine.
2. Update zone/shelf code.
3. Optionally add shelf photo.
4. Tap **Save medicine**.

## C. Add new medicine
1. Fill brand + generic + shelf code.
2. Add dosage/type/notes.
3. Turn on **Requires prescription warning** if needed.
4. Save.

## D. Scan packet
1. Open scan section.
2. Capture packet image clearly.
3. App tries barcode first; OCR if needed.
4. Confirm matched medicine and update location.

---

## 6) Good practices

- Keep shelf code format consistent (example: `A-03-2`).
- Add aliases for common misspellings.
- Add location photo for confusing shelves.
- Do not share your login password.

---

## 7) Troubleshooting

- App not loading: reconnect Wi-Fi and retry.
- Login fails: ask admin to reset password.
- Scan accuracy low: retake photo in good lighting.
- Upload failed: retry after connection stabilizes.
