# Staff Quickstart Guide (Phone-first)

## 1) Install app on phone (PWA)

### Android (Chrome)
1. Open app URL in Chrome.
2. Tap browser menu.
3. Tap **Install app** or **Add to Home screen**.
4. Open app from home screen icon.

### iPhone (Safari)
1. Open app URL in Safari.
2. Tap Share button.
3. Tap **Add to Home Screen**.
4. Open app from home screen icon.

## 2) Basic daily workflow

1. Sign in.
2. Search by brand, generic, or barcode.
3. Read location code and open photo.
4. Go directly to shelf.
5. If brand unavailable: press **Alternatives** to see same generic options + locations.

## 3) Add a new medicine

Required:
- Brand
- Generic
- Location code

Recommended:
- Barcode
- Package photo
- Location photo
- Prescription warning if required

## 4) Use smart batch scanner when shelves are rearranged

1. Enter location code once.
2. Press **Start scanning**.
3. Scan each medicine barcode one by one.
4. Press **Save scanned location updates**.

If camera fails, use manual barcode input field.

## 5) Prescription-warning medicines

- Tick **Requires prescription warning** in medicine form.
- Use **Prescription only** filter to review restricted medicines quickly.

## 6) Troubleshooting

- Can’t log in: ask manager to verify credentials.
- Camera blocked: allow camera permission in browser settings.
- Barcode not detected: improve lighting, hold steady, try manual input.
- No result found: search by generic name, then use Alternatives.

## 7) Golden rules

- This app is for **finding medicine locations**, not stock quantity.
- Keep location labels exact and consistent.
- Update location immediately after shelf moves.
